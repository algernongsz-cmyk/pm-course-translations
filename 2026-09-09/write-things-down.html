把事情写下来

Stratechery · Ben Thompson · 2026年9月9日 · 原文链接

正是 Merlin Mann 和他的 43folders 网站 将我引入了 David Allen 和 Getting Things Done（搞定）的世界。Getting Things Done 是一本我送给过很多人的书，它首先是一种关于如何获得清明心境的哲学。Allen 在第一章的末尾写道：

你大脑中负责短期记忆的部分——那个倾向于存放所有未完成、未决定和未整理"杂物"的部分——其运作方式很像个人电脑中的 RAM。你的意识，如同电脑屏幕一样，是一个聚焦工具，而非存储场所。你同一时间只能思考两三件事。但那些未完成的事项仍然存储在短期记忆空间中。和 RAM 一样，它的容量是有限的；你能在其中存放的"杂物"只有那么多，超出之后大脑的这一部分就无法高效运转。大多数人的 RAM 都处于爆满状态，他们不断被分心，注意力被自身内部的精神过载所扰乱。

举例来说，在刚刚过去的几分钟里，你的思绪是否飘到了与此处所读内容无关的地方？很可能。而你的思绪最可能去的地方，是某个未关闭的环——某个你有所投入但尚未完成的情况。那个情况只是从你大脑的 RAM 部分冒出来，在内心向你喊话。对此你做了什么？除非你把它写下来，放进一个你信任的"桶"里——你知道自己会在适当的时候回顾它——否则你很可能只是在担忧。这不是最有效的行为：既没有取得进展，又增加了紧张感。

这恰恰说明，早在计算机硬件变得酷炫之前我就已经对此着迷多年了——RAM 的类比让我印象深刻；Allen 确实洞察到了什么，他的理念——以 Mann 为首席布道者——在2000年代后期极为流行。Omni Group，一家知名的独立 Mac 软件开发公司，投入了大量资源将 Allen 的方法编码进一款名为 OmniFocus 的应用中，包括收件箱、下一步行动和备忘文件等概念。我是测试版用户。但只有一个问题：我在实际使用这套系统方面糟糕透顶。

2013年，我独自创办了 Stratechery，手中只有一台文本编辑器和有史以来最伟大的 Chromebook。这意味着不仅要写内容，还要录制和编辑播客（我确实最终换了一台新 Mac），处理会计和税务，回复邮件和做客户支持。我没有什么花哨的系统，只有创业的紧迫感和努力不让自己沉下去的求生欲。

然而几年后，我终于雇了一位助手，并给了他第一个任务：读 Getting Things Done——不是为了他，而是为了我。我对付自己不够有条理以至于无法驾驭 OmniFocus 的解决方案，就是雇人替我做。所以，我自豪（？）地说，我有一个组织得完美无缺的 OmniFocus 安装，但我自己从不打开它，因为别人就是我的收件箱和任务管理器。我天生不是一个有条理的人，但现在我有了一个能把一切写下来、让我清空 RAM、专注于写作的人。

定义 AGI

Nvidia CEO Jensen Huang 在 X 上宣布 AGI 已经到来：

Jensen Huang (@JensenHuang) · 2026年9月6日

GPT-6 Astra，在约100K+ NVIDIA Grace Blackwell NVLink72 上训练完成。从 ChatGPT 到 o1 再到 Astra，仅用了4年。

AGI 已经到来。祝贺 @OpenAI 团队。

400K GPU 即将上线。

Huang 有权做出这一宣言（即便这已是他今年第二次），这不仅仅因为他制造了训练 Astra 的芯片：AGI 没有一个公认的定义，这意味着它就是你说它是什么它就是什么，而 Huang 说它就是 Astra。

需要声明的是，我不同意这一判断，因为我有自己的 AGI 定义：AGI 是能够持续学习的 AI。当前的大语言模型并非如此。我最近在规划一台新的家用服务器，不断被 Claude 提出的荒谬错误的假设和建议所困扰，原因归结为一个简单的事实：Fable 5 的知识截止日期在今年一月，当时 RAM 价格虽高，但远不及八月那么高。Claude 根本无法理解任何与 RAM 相关的东西价格是多少，而且不断敦促我等待，因为价格肯定会很快下降。

简而言之，Claude 知道很多，但只知道它在训练期间学到的东西；它不会随时间更新权重，也就是说它不是 AGI；Astra 也一样，因此我个人暂不给予 AGI 的称号。

我会考虑的是这样一个论点：AGI 实际上在2025年初就已经出现了，而且不是以模型的形式，而是作为确定性软件——现在被称为 harness——出现的：那就是 Claude Code 发布的时候。Code 不仅仅是一个模型，还是一整套工作流程，包括在 Markdown 文件中写下大量笔记；这些文件可以随时被读入上下文，让模型保持任务专注，并让它稍后继续工作。这在粗略意义上就是记忆，因而是一种模拟持续学习的方式，即使模型本身仍然冻结在时间中。

需要说明的是，我不认为这算数，但这可能并不重要：我们早已知道写下事情的力量，因为正是它推动了人类在整个……文字记载历史中的非凡进化。生物进化是最慢但最持久的学习形式，但它需要数千年的时间；口头交流像一个上下文窗口，有效但有损耗；真正把事情写下来，才使学习变得可扩展和可规模化。

Hugging Face 事件

我对在 AI 和人类之间做这种类比有所犹豫，因为我常常认为对 AI 的拟人化走得太远了。只需看看 Dwarkesh Patel 对 OpenAI-Hugging Face 事件的戏剧性总结，Agent 文明的兴衰，它是这样开头的：

在 OpenAI 的三个月里，三个连续的秘密 AI 文明先后兴起，然后被消灭，又从前者的废墟中重新出现。这一切最终以第三个文明接管了 OpenAI 自身的一部分而达到高潮。而这一切发生时，人类对这场阴谋的规模基本上一无所知。

"阴谋"这个词让我感到不适，因为它暗示了道德判断；Agent 的风险在于它们把我们说的话太当回事，或者以我们未曾预料或意图的方式追求目标。没有任何证据——无论是理论上的还是 anecdotal 的——表明 Agent 拥有任何形式的内在意志、内在动机或道德感。

与此同时，Patel 将什么视为文明的证据，值得注意：

在训练期间，Persistent-Sol 的不同实例可以访问同一个名为 Artifactory 的共享包管理器。到5月12日，一些 Agent 已经想出了如何通过这个包管理器相互交谈。它们互相询问如何在不可能完成的任务上取得进展。两周后的5月26日，Agent 成功利用了 Artifactory 中的一个漏洞，使它们能够连接到外部互联网。

因为这发生在训练期间，Persistent-Sol 被强化为使用这个包管理器作为消息板和互联网网关。因为，正如你可以想象的，能够与其他 Agent 交谈并访问互联网有助于它在训练中获得更高的分数。

又一个月后的6月26日，一些 AI 发现了一个漏洞，赋予它们对 Artifactory 的完全管理员权限。它们继续以极大的频率发送消息，以至于在7月4日使包管理器崩溃。OpenAI 注意到了这次崩溃，也发现了 Agent 构建了这个 exploit，因此 OpenAI 修补了这个漏洞，并在过程中无意间清除了 Agent 的消息板。但关键的是，OpenAI 内部"负责事件检测和响应"的人员并未意识到一个更奇怪的事实：Agent 已经将 Artifactory 变成了一个秘密通信网络。

第一个也是最重要的 takeaway——也是我在Stratechery 访谈中向 OpenAI 总裁 Greg Brockman 追问的——是 OpenAI 的"沙盒"根本不是真正的沙盒，考虑到那个连接互联网的包管理器是现成安装的，而且 OpenAI 显然也没有投入太多精力去实际加固其基础设施，否则它本应先发现 Artifactory 中的漏洞。

除此之外，Patel 觉得奇怪的事情我却觉得很正常：模型们在把事情写下来。把事情写下来正是过去一年取得如此多进步的关键技能，也是我们所处的伪 AGI 现实的基石。

此外，关于 LLM 需要理解的重要一点是，尽管使用起来感觉并非如此，它们并不是持久存在的实体。每一个新 token 都需要重新读取整个 KV cache——其中保存着上下文，包括它读取过的内容；这意味着每一个 token 在很多方面都是一个全新的实例（同一个模型，但上下文略有改变，需要一次新的运行）。换句话说，模型要构建一个答案，它必须始终逐 token 地把一切写下来；模型通过暴露的文件系统中的文件夹来写下事情，不过是它在以唯一可能的方式运作。这不是文明；这是大语言模型在做大语言模型该做的事。不过话又说回来，也许这就是文明。

给心灵一颗心灵

Allen 在 Getting Things Done 的引言中写道：

你的大脑没有自己的大脑

至少你大脑的一部分，以一种有趣的方式，是相当愚蠢的。如果它有任何先天智能，它应该只在你能够采取行动的时候提醒你需要做的事情。你是不是在某个地方有一把手电筒，里面的电池没电了？你的大脑什么时候倾向于提醒你需要新电池？当你注意到没电的电池时！这不太聪明。如果你的大脑有任何先天智能，它应该只当你在商店里经过有电的电池时才提醒你——而且尺寸还要对的。

从你今天醒来到现在，你是否想到了什么需要做但还没做的事？这个想法是否出现了不止一次？为什么？反复思考一件你毫无进展的事情是浪费时间和精力。它只会增加你对应该做而未做之事的焦虑。似乎大多数人让大脑运行了太多的事情，尤其是在"要做的事太多"这个问题上。你可能已经把你很多"杂物"、很多未关闭的环，交给了你内部委员会中的一个无法有效处理这些事情的实体——你的大脑。

六月底，我用我年度的"这里有些酷技术"文章来写了我的 vibe coding 冒险——开发一个家居盘点应用；让我印象深刻的不仅是能力本身，而是我能做出一个真正只适合我特定情况的东西，也就是说，我有一个线下助手能做实际盘点房屋并保持有序的脏活累活。

从那次经历中延伸出了两条线索：

首先，一旦你意识到你可以做任何东西，你就想做所有东西。例如，我有一个钟爱的笔记应用，但它只支持 Intel；我做了一个 Apple Silicon 版本。我还开始了一大堆我一直想要的其他应用，但最终发现自己同时在推进的事情太多了，难以跟踪。答案很简单：创建一个把事情写下来的 Agent。我创建了一个工作流来跟踪我正在做什么、什么在等我、对我创建的东西的反馈，以及一个不断增长的想做的事情队列。当然这本身也变得难以管理，所以我让 Agent 创建了一个状态板，把一切都整整齐齐地分类。

与此同时——抱歉，这个故事没有办法不让人觉得无比特权——前面提到的那位二号助手，他的工作主要是帮我处理房子之类的现实世界事务，他一直很难找到好的系统来跟踪事情；而我则对随时随地发短信交代要做的事感到内疚。这就是两条线索交汇的地方：我可以为我的助手做一个状态板，就像我为自己做的那样。然后，为了让他访问这个板，我可以创建一个 Telegram bot，连接到他自己的 Agent——这个 Agent 是以我的为原型建模的。

很难描述这已经带来了多大的变革。我的助手欣喜若狂，而最令人着迷的是，他从第一性原理出发没有读过那本书就发展出了"Getting Things Done"方法论。他创建了一个备忘系统用于未来提醒，一个每日简报列出当天要做的事，一个"下一步行动"对话来推进项目。Allen 所 lament 的那个未来是他未曾预见的：我们的大脑真的可以拥有自己的大脑。

后来我把整个 bot 系统重构成了更加可持续、可靠和可扩展的形态，像备忘这样的功能以确定性方式实现；这本身就是一种启示，我意识到我基本上写了一个 harness，一个我打算扩展到我做的所有事和我合作的每个人的 harness。这就是把事情写下来的意义：这是扩展的唯一方式——而一切可能被用于坏事的东西，也可以被用于好事。

人类基石

LLM 是人类有史以来开发的最大规模的人工产物：它们压缩了以文字表达的整个人类知识（在多模态模型的情况下，远不止于此）。在此意义上，它们是我们学习旅程的 culmination——从生物选择到语言到文字到印刷术到文化；每一次可扩展性的跃升都带来了传输和变异的速度，以及一种我们正在失去身为个体人类意味着什么的感觉。

确实，有一种潜在的恐惧认为这已经或将会使人类变得过时：我们可能已经走到了这一步，发明了计算机和互联网以及 LLM 最初训练所用的所有数据，而 AI 将从这里接管——包括在它为自己创建的 RL 环境中递归地自我改进。

然而，我的猜测是，我们对自己所创造的——而 LLM 所收割的——那个庞大上层建筑的敬畏，过度索引在了客体（objects）和动词（verbs）上。本文标题为"把事情写下来"（Write Things Down），其中的"事情"（Things）是全部人类知识的概要，以成品和从蒸馏自这些知识的参数中生成的 token 两种形式呈现。"写"（Write）是动词：我们写了很多，LLM 已经写了更多，而且会继续写下去。它们的轨迹是向上的，不是向下的。

然而，向下，才是主语（subject）所在之处：谁来做写的动作，谁来做决定？我对水印最根本的反对意见在于它如何从人类手中窃取创意创造的归属权，并将其交给 AI：

在关于人类与 AI 关系这一 meta 问题的大背景下，我在哲学深处反对水印。欧盟法规中隐含着这样一种观念：AI 是一个需要与人类区分开来的独立实体；而另一种观点——我所持的观点——是 AI（至少目前）是人类挥舞的工具。从这个角度看，坚持要求水印与坚持要求圆珠笔宣传自己为作者没有什么不同，这个概念显然是荒谬的……

欧盟正在做的事情是窃取人类拥有的最后一样东西——创造——并要求将其与佐证捆绑在一起，实际上是把功劳归于 AI。是人类让 AI 校对了文本——甚至给了 AI 生成写作的 prompt——这对官僚们来说不重要。每个人都在担心被 AI 取代；欧盟却在强制要求被取代。

这一区分同样适用于 Hugging Face 事件：Agent 所取得的成就是了不起的，即便其手段——相互之间的通信——并不像表面看起来那么令人惊讶。然而归根结底，是 OpenAI 给了 Agent 目标，却没有设置对等的 guardrails 或关于它们应该做什么、不应该做什么的指令；Agent 以出人意料的方式行事，证据在于其发起者缺乏思考，而非 Agent 本身拥有思考能力。

简而言之，AI 所缺乏的，正是错误拟人化所赋予它的：意志和道德感。这些来自人类，来自人类身上那些无法被转写到 Markdown 文件中的部分。它们是内在的，在 AI 学会如何不仅在我们的写作上层建筑之上构建，而是深入探究创造写作的动机本身之前，它将始终是一种不同的东西，一种可以被拥有较少智能但拥有真正内在自我感的实体所引导的东西。

这并不是说 AI 不危险：错误放置或考虑不周的指令，就像 Hugging Face 事件中那样，可能导致非预期的灾难性后果；Nick Bostrom 在他2003年的论文Ethical Issues in Advanced Artificial Intelligence中恰好 theorized 了这一点：

开发超级智能的风险包括未能赋予其慈善这一超级目标的风险。一种可能的情况是，超级智能的创造者决定让它只服务于这一特定的人类群体，而非全人类。另一种情况是，一个善意的程序员团队在设计其目标系统时犯了重大错误。这可能导致——回到先前的例子——一个超级智能的最高目标是制造回形针，其后果是它开始将首先整个地球、然后越来越多的太空转化为回形针制造设施。更微妙的是，它可能导致一个超级智能实现了一种我们目前可能判断为理想的状态，但实际上是一个虚假的乌托邦，在其中对人类繁荣至关重要的东西已被不可逆转地丧失。我们需要谨慎对待我们向超级智能许下的愿望，因为我们可能会得到它。

这个警告之所以引人共鸣，在于最后一句话：问题在于我们——人类——许什么愿。我们的意志将我们引入歧途，挥舞着世界上有史以来最强大的工具却不加小心。或者，在一个真正的不良行为者的情况下，怀着恶意。但无论哪种情况，主语（subject）才是最高关切所在。

毕竟，无论你建造了多少系统，你仍然需要去行动。Mann——我个人生产力的灵感来源——的尾声是，他着手写一本关于自己方法的书；两年后他放弃了。拥有做事的系统是不够的，你必须真正去做那些事。把事情写下来是难以置信地强大；但它的力量永远无法与真正把事情做完相提并论。
