谁在害怕中国模型？

作者： Ben Thompson
原文： Who's Afraid of Chinese Models?
发布日期： 2026年7月21日

我在凯洛格管理学院的第一天有个故事，那是每位一年级MBA都必须修读的入门课程 STRT-431。我翻阅了阅读材料和案例研究，失望地发现课程中没有科技公司的案例。我就是这样的人，课后我去找教授询问原因，他告诉我这门课的目标不一定是学习特定行业，而是揭示可以应用于任何行业的任何公司的广泛适用的普遍原则。

我——正如我通常讲述这个故事时说的——对此并不满意：对我来说，科技的本质，尤其是软件和分发的零边际成本（以及零交易成本）这一事实，是某种根本性的不同；在公式中填入零往往会造成混乱！然而我很快意识到，这正是我的机会。聚合理论的基本洞察是，零边际成本导致了与人们曾经从互联网预期的根本不同的价值链：在一个控制需求比分发供应更重要的世界里，出现了中心化和规模化。

然而，AI 的迷人之处在于那些古老的普遍原则正在重新回到前沿。这一点在这个周末表现得淋漓尽致，X 平台上关于 Kimi K3 的含义争论不休——这是中国推出的另一个开放权重模型，在能力方面接近最先进水平。简而言之，边际成本以重大方式回归了，既体现在最先进免费模型的短期影响上，也体现在行业的长期结构上。

COGS 与 R&D

支撑开放权重模型讨论的最常见误解之一是它们更便宜——甚至免费。毕竟，你可以直接下载权重，跳过创建自己模型所需的时间、费用和能力。这当然是正确的，但这种情况下的"免费"是指你需要花费在研发上的金额；R&D 是一项独立于你产生的收入的固定费用。如果你在 R&D 上花费了100万美元，无论你的收入是10万美元还是1亿美元，你仍然花费了100万美元的 R&D（当然，这确实会影响你的盈利能力）。

与收入相关的是 COGS——销货成本——而 AI 的 COGS 是真实存在的，这是很长一段时间以来软件领域所没有的。具体来说，在模型上运行推理——无论是 Kimi 还是 Fable——都需要成本，而且 AI 提供商在推理上花费的金额，至少在大多数商业模式中，与收入直接相关。重复上面的例子，产生1亿美元收入与10万美元收入相比，可能需要1000倍的 COGS。具体而言，如果生成带来1美元收入的 token 需要50美分，那么1亿美元收入将有5000万美元的 COGS；10万美元收入将只有5万美元的 COGS。

就开放权重模型而言，它们的提供服务并非免费。Kimi K3 定价为每百万输入 token 3美元，每百万输出 token 15美元；这比 Sol 的每百万输入 token 5美元和每百万输出 token 30美元要便宜，但这甚至可能不是正确的衡量标准。

Token 与智能

Nvidia CEO 黄仁勋将 Nvidia 正在构建的内容描述为"token 工厂"，从 Nvidia 的角度来看，这种框架是有道理的。Nvidia 的 GPU 与模型无关：它们生成 token，并以最快、最高效的方式实现。这导致了诸如每秒 token 数、首 token 延迟、每瓦特 token 数、token 成本等衡量标准，黄仁勋认为这些指标将成为决策的基础。

这种框架在 AI 的第一个范式——ChatGPT 时代——确实有意义，那时 token 直接传递给最终用户。然而，AI 的第二个范式——推理时代——打破了这种衡量方式。推理意味着思维链 token 的爆炸式增长，不同的模型需要不同数量的推理 token 才能得出正确答案。例如，据报道 Kimi 使用的 token 比 Sol 多得多，使其价格优势变得毫无意义。Agent 引入了类似的动态：某些模型在执行 agent 工作流所需的 token 数量方面比其他模型更高效。

这意味着 token 不是商品。商品的定义特征在于它是可替代的：一加仑石油就是一加仑石油；一吨铜就是一吨铜；一蒲式耳小麦就是一蒲式耳小麦。然而，来自一个模型的 token 与来自另一个模型的 token 不相同。可替代的是从 token 构建的内容，也就是智能。换句话说，如果 Kimi 和 Sol 都生成了正确答案，那么该答案是可替代的；为了得到该正确答案而生成的 token 差异是 COGS 差异的一个促成因素。

智能的 COGS 是几个不同因素的函数：

  • 模型足迹：权重和运行时状态决定了托管每个服务副本所需的昂贵内存和加速器数量。
  • 推理效率：架构选择（如 Mixture-of-Experts）减少了每个生成 token 的计算量。
  • 内存效率：架构选择可以减少 KV cache 需求，允许更多并发请求和更好的 GPU 利用率。
  • 服务效率：批处理、调度、前缀缓存和其他推理优化最大化利用率并在请求之间共享工作。
  • Token 效率：达到正确答案所需的 token 越少，推理成本就越低。

之所以这很重要，是因为我们正在迅速接近这样一种状态：对于许多经济上有益的任务，智能实际上是一种商品。例如，任何构建基本 CRUD 应用的人，都可能可以使用多个提供商的模型来实现。而且，在商品市场中，盈利的途径不是通过收取更高的价格——同样，你可以（或很快将能够）使用多个模型制作完全相同的应用——而是通过拥有优越的成本结构。

理解商品市场

这里值得逐步分析其机制，因为正如我几个月前在亚马逊的持久性中指出的那样，商品市场的动态并不是科技界人士通常熟悉的：

  • 在商品市场中，每个人都收取相同的价格，因为每个人都在销售同样的东西；该价格由供需决定。
  • 商品的需求是价格弹性的函数：商品越便宜，对它的需求就越大，反之亦然。
  • 商品的供应是生产商品的边际成本的函数。

需要理解的关键点是，生产商品的边际成本因供应商而异。这意味着在实践中，成本结构最差的供应商最终以他们的边际成本销售商品（如果他们能够生产的话）；其他所有人的利润取决于他们的成本结构优于边际供应商的程度。

举个例子：

  • 供应商 A 可以以每个10美元的价格生产10个单位的商品
  • 供应商 B 可以以每个15美元的价格生产10个单位的商品
  • 供应商 C 可以以每个20美元的价格生产10个单位的商品

让我们假设价格弹性使得在20美元时有25个单位的商品需求。这意味着：

  • 供应商 A 将以每个20美元的价格销售10个单位的商品，每单位赚取10美元
  • 供应商 B 将以每个20美元的价格销售10个单位的商品，每单位赚取5美元
  • 供应商 C 将以每个20美元的价格销售5个单位的商品，每单位赚取0美元

这并不完全正确：供应商 C 承受短缺的原因是供应商 A 和 B 将能够在价格上略微低于他们，这当然会影响需求（这是弹性的），但这说明了问题。供应商 A 有一家伟大的企业，供应商 B 有一家好的企业，而供应商 C 将要破产。

破产风险是固定成本重新回到前沿的地方：供应商 C 既有固定成本（如潜在的 R&D 支出），还可能承担了生产商品所需设备的债务。它不能在定价时考虑这些成本——记住，市场出清价格近似于满足需求所需的最高成本单位的边际成本——但这些成本绝对可能导致供应商破产。而且，如果该供应商破产，那么价格上涨，直到另一个供应商决定进入（或其他供应商扩张）。

智能市场

让我们回到模型。目前，上述分析都不适用，因为前沿模型的需求超过供应，而且供应受到算力不足的限制。这种算力短缺不仅意味着像 Nvidia 这样的算力供应商赚取非常高的利润率，而且 Nvidia 的客户，如 SpaceXAI，也可以将算力以高利润率转售给像 Anthropic 这样的公司。与此同时，Anthropic 可以支付加价，因为他们可以以更高的加价销售 token。

然而，给予 Anthropic 优越利润率的不仅仅是过剩需求：得益于模型能力、服务规模和 token 效率，Anthropic 和 OpenAI 可能拥有最低的前沿质量智能单位成本。他们以特定的能力水平服务模型数月，领先于竞争对手，同时将最好的模型应用于优化这些成本。

也值得注意的是，市场尚未将智能视为商品：需求是针对 Anthropic 和 OpenAI 的，而不是针对不那么好的模型（因此 SpaceXAI 和 Meta 向 Anthropic 出售产能）；考虑优化成本推动的一种方式是，这是通过智能水平定义待完成工作的功能，以便智能买家可以创建一个智能被商品化的市场。然而，从长远来看，无论谁在前沿，都最有能力主导非前沿市场，这些市场只是前沿减去 n 个月，即前沿模型制造商一直在优化其服务成本的那几个月。

所有这一切都意味着，我认为对 Kimi 和中国模型的反应——至少从经济角度来看——是相当过度的。目前存在一个价格保护伞，这是算力短缺的下游产物；我高度怀疑中国模型在边际成本基础上是否更便宜，它们看起来更便宜只是因为 Anthropic 和 OpenAI 如此受供应限制，以至于他们收取的价格远高于如果有足够的供应来满足智能需求时的价格。

前沿实验室的偏执

那么，为什么模型制造商似乎对中国模型如此恐慌？

首先，我认为前沿实验室锚定在一个训练成本主导其财务建模的世界中。只要训练消耗的 GPU 多于推理，最大化推理收入以帮助资助下一次训练运行就至关重要，这意味着对推理收取非常高的价格。

然而，展望未来，我预计推理市场的增长速度将远快于训练成本（这包括训练成本将继续飙升的假设），这意味着他们确实可以通过规模来弥补。就在八个月前，这还不清楚是否会成为现实，但 agent 范式的解锁如此巨大，以至于前沿实验室应该更有信心，他们不仅能够生存，而且能够在更低的价格下蓬勃发展（一旦他们有足够的算力）。

其次，智能实际上不是一个完美的商品，部分原因是应用智能使自己变得更聪明。具体来说，运行推理的人也在收集数据，而这些数据用于使模型的下一次迭代变得更好。一方面，这是前沿实验室在更多算力上线时降低价格并增加使用量的更多理由；另一方面，这就是为什么像微软这样的公司越来越着迷于帮助公司运行自己的模型。如果中国模型是可行的替代方案，那会更加可行。

第三，前沿实验室不仅可以从中国模型中分化出来，而且可以相互分化的另一种方式是继续向上整合到客户体验中。令人惊讶的是，Claude Code 和 Codex 证明相当有粘性；无论你开始使用哪个 harness，都可能是你坚持使用的那个，而且对于非技术用户来说更是如此。而且，从长远来看，这种向上移动技术栈的必要性确实意味着前沿模型对软件提供商构成威胁，包括微软。另一方面，目前拥有客户体验的软件公司如果有竞争模型的访问权限，就是他们能够抵抗前沿实验室侵蚀的程度。

最后，Anthropic 特有的意识形态角度不容忽视。这是一家认为只有它可以被信任处理 AI 的公司，而开放权重替代方案的存在对这一假设造成了致命打击。

中国的动机

Kimi 并不是唯一的新中国模型；来自彭博社：

阿里巴巴集团控股有限公司股价周一上涨多达5.4%，此前该公司推出了其旗舰 Qwen3.8 Max 模型的预览版，称其仅次于 Anthropic PBC 的 Fable 5。周日的发布仅几天前，初创公司 Moonshot AI 推出了一款强大的新产品，搅动了市场，并引发了美国对中国缩小与 Anthropic 和 OpenAI 等全球领导者差距的担忧。Qwen3.8 Max 拥有2.4万亿参数，加入 Moonshot 的 Kimi K3 进入重量级阵营。K3 拥有2.8万亿参数，与顶级产品相媲美，而阿里巴巴也设定了类似的高期望。

开发者现在可以通过阿里巴巴的编码平台（包括 Qoder）访问 Qwen3.8 Max。阿里巴巴计划很快使该模型开放权重，将访问扩展到预览版之外。对这些中国制造的 AI 系统和模型的兴趣如此之高，以至于 Moonshot 被迫在周日晚些时候暂停接受新订阅，以应对压倒性的需求。

Qwen3.8 Max 也将开放权重这一事实值得注意。阿里巴巴在今年早些时候停止为其领先模型发布权重，但似乎已经恢复了这一改变；我怀疑这一转变与上周习近平关于 AI 的讲话有关，该讲话加倍强调了开放权重方法：

我们应该坚持开放共赢原则，促进创新驱动发展。作为世界经济增长的新引擎和增长动力转换的加速器，AI 正在从数字世界进入物理世界。我们应该抓住这一难得的历史机遇，鼓励开源、开放、协作和共享。我们应该促进 AI 的技术创新、产业发展和基于场景的应用。我们应该协调推进传统产业的转型升级、新兴产业的培育壮大和未来产业的前瞻性规划，使各部门和各行业都能从 AI 中受益。

中国的战略显而易见：商品化你的互补品。请注意，习近平明确将开放性与 AI"从数字世界进入物理世界"联系起来；物理世界是中国主导的世界，该国在机器人等领域的领先优势将大大受益于广泛可用的 AI 模型。

同样，中国不希望美国在 AI 方面获得不对称优势；在某种程度上，中国可以削弱美国前沿实验室，同时加强所有潜在的美国对手，那就更好了，而且它可以受益于将依附于开放生态系统的创新。

蒸馏问题

同样，不要指望中国会对前沿实验室的蒸馏攻击采取任何行动。我认为将中国实验室的所有成功归因于蒸馏是错误的，但假装蒸馏没有给中国实验室带来巨大优势同样是错误的。随着后训练强化学习在过去一年中变得越来越关键，这一优势真正显现出来。中国实验室不必从零开始构建强化学习环境，只需使用前沿实验室模型作为教师，就能以低得多的成本快速改进（这不是中国模型开发成本更低的唯一原因，但这是一个重要原因）。

有趣的是，西方中国模型最重要的用例之一本身就是蒸馏。例如，刚刚发布了开放权重模型的 Thinking Machines，依赖中国模型解决强化学习的冷启动问题。Dean Meyer 和 Konstantine Buhler 在 X 上写了一篇出色的文章，解释了蒸馏意味着西方开放权重模型相对于中国处于根本性劣势：

蒸馏并不能解释中国开放模型领先优势的全部。中国实验室拥有世界级的研究人员、大量算力、强大的预训练模型、软硬件协同设计以及快速改进的后训练能力。但蒸馏压缩了强大基础与接近前沿系统之间昂贵的最终差距。即使蒸馏只占中国模型总能力的较小份额，它也占其相对于美国开放模型优势的相当大份额。

新的执行机制将使中国公司的大规模蒸馏变得更难、更慢、更昂贵。然而，执行并不能消除由国家行为者支持的蒸馏。西方前沿的每一次进步因此为中国实验室创造了另一个教师。西方构建者要么必须独立复制这些能力，要么等待从中国模型中学习。这一差距使中国实验室相对于西方公司拥有持续的结构性优势。

这一点值得重复：因为美国开放权重模型制造商必须遵守前沿实验室的服务条款，他们(1)比中国替代方案更差，(2)最终蒸馏了蒸馏，只是绕道中国实验室。如果西方开放权重模型制造商能够直接访问源头不是更好吗？

为此，围绕蒸馏还有一个更有趣的问题：为什么它不好？毕竟，大型语言模型不就是对开放互联网上所有知识的蒸馏吗？由前沿实验室抓取并蒸馏成模型，而这些模型本身又被蒸馏？谁在这里被错误对待了？

事实上，这个悖论就是解决方案。我认为开放权重模型对创新有益（而且，如上所述，我认为前沿实验室会很好），但依赖中国是个问题。美国应该通过一项法律，(1)明确规定收集训练模型的数据是合理使用，(2)禁止禁止蒸馏的服务条款，至少对美国公司如此。阻止蒸馏——这实际上只是查询 API——几乎是不可能的；美国应该走另一条路，采用新的版权政策，既为实验室提供免责，又保证他们学到的东西为其他所有人推动进一步创新。

害怕的理由

整篇文章都是在化解对 Kimi K3 以及总体上中国开放权重模型的过度反应；然而，有一个值得关注的理由，那就是网络安全。考虑来自The Stack的这个故事：

Hugging Face 表示其生产基础设施上周早些时候遭到"自主"AI agent 系统的入侵。该平台的安全团队最初在事件响应(IR)中受挫，原因是未具名的美国 LLM 前沿模型护栏"无法区分事件响应者和攻击者"，他们表示。因此 Hugging Face 的防御者转而使用中国 Z.ai 实验室的开源 GLM 5.2 模型——在他们自己的基础设施上运行，分析攻击者留下的17,000多个日志或足迹。

对于总部位于纽约的 Hugging Face 来说，这是一个引人注目的公开承认，该公司让用户协作模型、数据集和应用程序，今年夏天达到了1亿美元 ARR 里程碑。在事件报告中，公司建议防御者"有一个可以在你自己的基础设施上运行的强大模型[我们的斜体]，在事件之前经过审查和准备，既为了避免护栏锁定，又为了防止攻击者数据和凭据离开你的环境。"

特朗普政府对 Anthropic 发布 Fable 的恐慌反应是多么错误，这很难高估，尤其是因为它加剧了 Anthropic 最糟糕的倾向，即假设只有他们可以被信任拥有强大的 AI。在只有一个 AI 的世界里，将最强大的网络安全能力保留给美国政府和受信任的盟友可能是有意义的；然而，那不是我们生活的世界。

有并且将有能够对现有基础设施发起网络安全攻击的模型，而且这些模型将——已经——广泛可用。最好的防御——事实上唯一可行的防御——将是确保防御者也能获得最好的模型。目前，由于特朗普政府的指令，防御者实际上被禁止使用 Fable 或 Sol 进行网络安全；这意味着最好的替代方案是使用多年来一直试图削弱我们网络防御的国家的模型。这太疯狂了！

更好的路线很明确：首先，放宽对 Fable 和 Sol 网络安全的限制，其次，确保美国开放权重模型制造商与中国处于平等的竞争环境。是的，前沿实验室会对此大声抱怨，但政府应该意识到，听从他们的歇斯底里已经导致美国处于美国公司依赖中国进行防御的境地。让前沿实验室通过做得更好而获胜；不要让他们定义安全或保障，或者收起人类集体知识的梯子。中国已经足够难竞争了；让他们为开放和创新树立标杆简直是在放弃我们最大的优势。
